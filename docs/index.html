Lumenveil (32-bit client only)

  1. Install/update the client through the launcher.
  2. Keep the game closed and run Lumenveil-Setup.cmd once (1-5 minutes, reads your own game files).
  3. Start the game with Ascension.exe. Ctrl+F12 toggles Lumenveil, Ctrl+F7 opens its settings.

Do not start CoACustomRace.exe with this installed — the 32-bit version.dll breaks the 64-bit client.

Some antivirus products quarantine version.dll (proxy DLL). Allow it if the visual layer does not appear.

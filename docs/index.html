Lumenveil (built into the 64-bit client)

The 64-bit CoACustomRace.exe contains the Lumenveil visual layer. Start the game with it; nothing needs to be installed for the visuals.

  1. Optional, recommended once: close the game and run Lumenveil-Setup.cmd (1-5 min, reads your own files, writes lampdata.bin/liquiddata.bin).
  2. Start the game. Ctrl+F12 toggles Lumenveil, Ctrl+F7 opens settings, Ctrl+F3 per-zone looks.

No 32-bit version.dll is shipped: it would break the 64-bit client.
